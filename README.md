# Caixa eletrônico em python 🐍

* Caixa eletrônico simples para treinar a lógica de programação em python

## 🚀 Funcionalidades

* O usuário digita um número
* O programa soma todos so números até o usuário digitar o 0 (break)
* Utiliza laço de repetição while e break para processamento

## 🛠️ Tecnologias

* Conceitos de: input de dados, F-string, estruturas de repetição e break

## 📖 Como executar

Basta ter o programa Python instalado e rodar o programa:

```python 
python caixa_eletronico_acumulador.py 
```
